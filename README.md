📊 Student Result Management System (Java + DSA)
📌 Overview

This is a simple console-based Student Result Management System built in Java. It helps manage student records using basic Data Structures and Algorithms concepts like ArrayList, searching, and sorting.

The project is designed as a beginner-friendly DSA implementation to demonstrate how core programming concepts can be used in real-life systems.

🚀 Features
Add new student records
View all students with grades
Search student by roll number
Sort students by marks (High → Low)
Automatic grade calculation (A, B, C, D, F)
🛠️ Technologies Used
Java (Core)
ArrayList (Data Structure)
Console-based UI
Basic DSA (Searching & Sorting)
📚 Concepts Covered
Object-Oriented Programming (OOP)
Classes and Objects
ArrayList usage
Linear Search
Bubble Sort Algorithm
Conditional Logic
▶️ How to Run
1. Clone the repository
git clone https://github.com/your-username/student-management-system.git
2. Open the project

Open the .java file in any IDE (IntelliJ, Eclipse, VS Code)

3. Compile the program
javac StudentManagementSystem.java
4. Run the program
java StudentManagementSystem
